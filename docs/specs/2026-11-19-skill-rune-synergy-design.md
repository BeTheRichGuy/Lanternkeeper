> 희승 요청: "Idle 게임은 VFX랑 스킬셋 보는 맛이 제일 중요하니깐, 스킬트리랑 룬 같은 거 리서치 많이 해서 밸런스 생각하고, 조합 시너지 뽕맛 나오게 설계. 뻔한 스킬도 몇 개, 뻔하지 않은 독창적인 스킬도. VFX도 기깔나게."
> 근거 리서치: `docs/research/skill-rune-synergy-research.md` (게임 16종, 패턴 12개, 밸런스 원칙, 독창 메커니즘 35개).
> 이 문서는 GDD §5.1(공명 쌍 표·사망 전파)과 §5.4(곱연산 공식)를 대체하고, §7(클래스)·§8.5~8.7(정수·고유·룬)을 구체화한다. 수치는 모두 초기값이고 Sim 표본 시뮬로 교정한다.

## 0. 한 줄 요약

**"앞 칸이 새기고, 뒤 칸이 터뜨리고, 죽음이 퍼뜨린다."** 고리 순서(시계 방향)가 각인 → 공명 → 사망 전파의 연쇄를 설계하는 퍼즐이 되고, 같은 행동을 쌓으면 스킬이 **진화**하고 공명이 **숙련**되며, 공명이 쌓이면 화면 전체가 터지는 **대공명**이 온다.

## 1. 뽕맛이 나는 다섯 층

| 층 | 무엇이 터지나 | 언제 | 근거 패턴 |
|---|---|---|---|
| 1. 각인 | 적 몸에 원소 색이 입혀진다 | 매 시전 | P1 표식 |
| 2. 공명 | 다음 원소가 각인을 터뜨린다(원소마다 다른 효과) | 초당 수 회 | P1·P10 순환 |
| 3. 사망 전파 | 각인 적이 죽으면 옆으로 번지며 줄줄이 터진다 | 몰이 방 | P2 사망 연쇄 |
| 4. 대공명 | 공명 게이지가 차면 화면 전체 원소 폭발 | 30~60초마다 | P9 충전→해방 |
| 5. 진화 | 많이 쓴 스킬이 이름·모양·규칙이 바뀐다 | 수십 분~수 시간 | P6 진화, P11 카운터 |

방치 게임이라 **손으로 조작하지 않아도 매 순간 1~2층이, 1분마다 4층이, 몇 시간마다 5층이** 일어나게 설계한다.

## 2. 원소 순환 공명 (GDD §5.1 개정)

### 2.1 순환
```
 잿불 ──▶ 서리 ──▶ 전격 ──▶ 부패 ──▶ 공허 ──▶ (잿불)
```
- **정방향 공명**: 적에게 남은 각인 X를 순환상 **다음 원소**가 맞히면, X 고유의 큰 공명이 터진다. 외울 것은 "다음 원소가 터뜨린다" 한 줄이다.
- **불꽃(약공명)**: 그 밖의 다른 원소가 맞히면 작은 불꽃(추가 피해 +30%, 게이지 +0.3). 어떤 조합도 손해는 아니게 한다. 방향을 맞추는 게 고리 순서 퍼즐의 보상이다.
- **중첩**: 같은 원소를 다시 맞히면 중첩(최대 5, 중첩당 피해 +10%). 기존 유지.

### 2.2 정방향 공명 5종
| 각인 → 터뜨리는 원소 | 공명 | 효과 (초기값) | 화면 |
|---|---|---|---|
| 잿불 → 서리 | **파쇄** | 맞은 피해 ×1.5 + 반경 1.2칸 50% 파편 | 주황 균열 → 청백 파편 |
| 서리 → 전격 | **과부하** | 기절 1초 + 가장 가까운 2명에게 번개 튐(40%) | 노랑 지그재그 |
| 전격 → 부패 | **역병 전도** | 반경 2칸 적에게 부패 각인 전염 + 3초 지속 피해 | 연두 방울 확산 |
| 부패 → 공허 | **포식** | 맞은 피해 ×1.2 + 영웅 체력 2% 회복 + 게이지 +1 추가 | 보라 흡입 → 영웅에게 빛줄기 |
| 공허 → 잿불 | **붕괴** (신규) | 반경 2.5칸 적을 터진 지점으로 0.6칸 끌어당김 + ×1.3. **적을 뭉쳐 사망 전파를 키운다** | 보라 수축 → 주황 폭발 |

- 붕괴는 "몰이 AI 없음"(스파이크 결론) 대신 **빌드로 몰이를 만드는** 장치다. 끌어당김 거리는 짧게 두어 화면이 어지럽지 않게 한다.
- 공명 폭발은 **독립 피해 원천**이다. 스킬 수정자는 받지 않고 **공명 버킷**(§4)만 받는다(PoE Detonate Dead식 분리).

### 2.3 공명 게이지 → 대공명
- 정방향 공명 +1, 불꽃 +0.3, 사망 전파 홉 +0.2. **40**이 차면 대공명.
- 대공명: 영웅 중심 반경 5칸, 마지막 공명 원소의 정방향 공명을 범위 안 모든 적에게 한 번에 건다 + 그 원소 각인을 새긴다. 1.2초 연출, 화면 흔들림, 라이트 섬광.
- 오프라인: 게이지 충전 속도는 측정 기반(최근 30분 평균)이라 별도 계산 없음.

### 2.4 공명 숙련 (듀오 공명)
- 정방향 공명을 종류별로 누적 집계(영구, 환생해도 유지).
- 단계: 300회 → **숙련 I**(+15% 공명 피해), 2,000회 → **숙련 II**(+30%), 10,000회 → **숙련 III**(규칙 추가).
  - 파쇄 III: 파편이 서리 각인을 남긴다(파쇄가 과부하로 이어진다).
  - 과부하 III: 번개 튐 2 → 4.
  - 역병 전도 III: 전염 반경 2 → 3칸.
  - 포식 III: 회복 2% → 3%, 게이지 추가 +1 → +2.
  - 붕괴 III: 끌어당김 뒤 0.5초 기절.
- 우연이 아니라 **누적 행동으로 해금**(Hades 듀오의 불운 문제를 피함, GDD 기둥 4).

## 3. 사망 전파 (GDD §5.1 개정: 예산과 감쇠)

| 장치 | 값 | 이유 |
|---|---|---|
| 홉 감쇠 | 홉마다 ×0.85 | 길어질수록 약해져 폭주 방지 |
| 홉 상한 | 기본 6 (정수·문양·스킬로 최대 +3) | 스파이크 최대 7에 맞춤 |
| 틱당 예산 | 한 틱(0.1초)에 전파 24개 | 넘치면 다음 틱으로 미룸 |
| 중복 금지 | 한 연쇄가 같은 적을 두 번 맞히지 않음 | 기존 유지 |
| 전파 유래 공명 | 피해 계수 ×0.7 | 몰이 빌드가 보상받되 상한이 생긴다 |

- 화면: 전파는 폭발 N개가 아니라 **한 줄기 선(원소색 잔불 줄기)**이 이어지며 그 끝마다 작은 파열. 연쇄 길이는 라벨 "연쇄 ×7" 하나.

## 4. 피해 공식 (GDD §5.4 개정: 곱연산 3카테고리)

```
피해 = 기본 피해 × 스킬 위력
     × (1 + Σ가산%)                         ← 장비·탤런트·문양의 "피해 +%", 상한 없음
     × A(스킬 개조) × B(정수·고유) × C(조건)  ← 카테고리당 하나, 같은 카테고리끼리는 가산 합산
     × 치명(1.5 + Σ치명 피해)
공명 폭발 = 맞은 피해 × 공명 배수 × (1 + 공명 피해% + 숙련%)   ← 스킬 수정자 미적용
```
- A: 문양·진화·작열의 곱연산. B: 정수·고유의 곱연산. C: 처형·군중·순서 보너스 같은 조건부.
- 목표: 같은 장비에서 최고 빌드 ≤ 중앙값 × 3, 최저 ≥ 중앙값 × 0.5. 무작위 빌드 표본 시뮬로 점검.

## 5. 고리 규칙 (GDD §5.1 구체화)

- 기본 공격 1 + 고리 4칸(+ Lv30 궁극 1). 쿨다운이 끝난 스킬 중 **고리 순서대로** 시전.
- **역할 태그**: 오프너(각인을 새김) / 연장(퍼뜨림·뭉침) / 피니셔(각인을 소비해 크게). **앞 칸이 남긴 각인을 바로 다음 칸이 터뜨리면 공명 +20%**(순서 보너스, C 카테고리).
- **문양(보조 룬) 소켓**: 칸마다 문양 1개(Lv25부터 2개). 문양은 **자기 칸과 시계 방향 다음 칸**에 적용된다(방향성 인접, Rite Link). 같은 문양 둘은 겹치지 않는다(하나만).
- **봉인 슬롯**(Lv30, 설계만): 고리에서 뺀 스킬 1개가 "공명이 터질 때 15% 확률로 자동 시전"되는 패시브가 된다. `triggered` 표시, 다른 프록을 못 건다.

## 7. 진화 (P6) — 스킬마다 1개

- 조건 **세 가지 중 두 가지**: ① 그 스킬 누적 시전 N회(기본 800, 핵심 600, 고급 400) ② 지정 문양을 단 채 ③ 지정 정수 장착.
- 진화하면 이름·VFX·규칙이 바뀌고 도감에 등록. 해금은 환생해도 유지. 진화 가능 상태면 고리 칸이 은은하게 빛난다.
- 진화는 숫자만 올리지 않고 **규칙이 하나 바뀐다**("더 세다"가 아니라 "다르게 세다").

## 9-3. 나머지 직업의 "별난 규칙" (요약)

- **바람사냥꾼** (집중): 덫에 각인을 새겨 두면 덫이 터질 때 사망 전파가 시작(점화 장치). 독창: **바람길**(화살이 지나간 줄이 2초 남아, 지나는 다른 투사체가 갈라짐), **폭풍의 눈**(정지 상태로 집중할수록 관통 증가).
- **별점술사** (시간): 고리 되감기 전담. 별의 축복 중에는 고리 마지막 스킬이 첫 스킬을 한 번 더 호출. 독창: **시간 정지**(멈춘 동안 받은 공명이 해제 때 한꺼번에 터짐), **별자리 잇기**(각인 적 3명 이상이 별자리로 이어져 선을 따라 피해).

## 10. 정수·고유·룬어 방향

- 정수 120종의 절반 이상을 **규칙 변경 + 대가** 또는 **카운터형**으로. 확률 프록은 쿨다운 비례(Grim Dawn), `triggered` 재발동 금지.
  - 예: "각인은 전파되지 않지만 공명 폭발 ×2" / "사망 전파 반경 ×2, 홉 감쇠 ×0.7" / "고리 3바퀴마다 첫 스킬 두 번 시전" / "대공명이 두 원소로 터진다, 게이지 60".
- 룬어(GDD §8.7)는 소켓 순서형 10개 유지. **고리에서 쓴 원소 순서**가 룬어가 되는 변형(Last Epoch 룬 발동)은 확장 후보.

## 11. VFX 원칙과 목록

- 원소 색+모양 이중 부호: 잿불 주황 불꽃 / 서리 청백 결정 / 전격 노랑 지그재그 / 부패 연두 방울 / 공허 보라 소용돌이.
- 가장 밝은 값은 타격 순간 1~2프레임, 개별 효과 0.2~0.5초, 장판만 길게. 등불 빛을 이기지 않게. 큰 효과는 라이트 섬광(실제 2D 라이트)과 짝.
- 이벤트 예산: 틱당 연출 상한, 넘치면 묶음 연출. 피해 숫자는 치명·공명·전파 합계만.
- 필요한 VFX(하위 세션에서 PixelLab으로 제작): 공명 5종(파쇄·과부하·역병 전도·포식·붕괴), 대공명 5종(원소별), 사망 전파 줄기, 잿불기사 신규 스킬(잿불 베기, 서리 낙인, 잿더미 도약 착지, 폭풍 가르기, 용광 일격, 쇠사슬 끌기, 재의 메아리 분출, 화산 균열 분출, 녹은 심장, 서리불꽃 갑옷 오라, 대장장이 망치, 대장간의 심판, 꺼지지 않는 불), 진화판 대표 4종(쌍날 잿불, 불꽃 소용돌이, 유성 낙하, 천둥 가르기). 나머지 진화는 색·크기 변형.

## 12. 구현 순서

1. Sim 엔진: 피해 버킷, 원소 순환 공명 + 붕괴, 공명 게이지·대공명, 숙련 집계, 사망 전파 감쇠·예산, 스킬 모양(근접 단일·원·부채꼴·직선·도약·끌어당김·지연 낙하·버프·오라·무장), 열기와 작열, 문양, 진화 조건·해금, 세이브.
2. 잿불기사 16종 데이터 + 추천 고리 3개, 레벨 해금.
3. View: 스킬별 VFX(기존 게임팩 + 신규), 공명·대공명·전파 줄기 연출, 라이트 섬광, 고리 HUD(게이지·진화 표시), 고리 편집 패널.
4. 테스트: 순환 공명표, 감쇠·상한·예산, 진화 조건, 숙련 단계, 버킷 계산, 결정성, 세이브 왕복, 무작위 빌드 DPS 분포 점검.

## 13. 내가 정한 것 (희승 확인 부탁)

리서치가 "결정 필요"로 남긴 다섯 가지를 자동 진행 지시에 따라 이렇게 정했다.
1. 곱연산 3카테고리 구조 → **채택**(§4).
2. 공명 5각 순환 → **채택**, 기존 4공명은 순환 위로 재배치, 공허→잿불 **붕괴** 신설(§2).
3. 시체 불씨 → **보류**. 대신 재의 메아리·녹은 심장이 "사망 전파를 다시/강제로 시작"하는 역할을 맡는다.
4. 봉인 슬롯 → **Lv30 이후로 설계에만 넣음**(§5), 구현은 궁극 슬롯과 함께.
5. 진화 → **스킬마다 1개**, 대표 진화만 새 VFX, 나머지는 색·크기 변형(아트 예산).
