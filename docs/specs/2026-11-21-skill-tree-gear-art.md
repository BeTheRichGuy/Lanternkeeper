# 스킬 트리 · 장비창 아트 재설계 (2026-11-21)

희승(11-21, 새 장비창·고리 창을 보고): "장비창도 조금 더 개성있게. 저 GUI 디자인은 다시 하는게 좋겠다. 저 네모 박스 자체가 너무 못생긴 것 같아. 스킬도 스킬 트리 형태로 다시 기획해서 만들어보는게 좋을 것 같은데."

[전면 재기획서](2026-11-21-total-redesign.md) §5.4(장비창)·§5.6(고리 창)을 구체화한다. 스킬 체계는 [스킬·룬 설계](2026-11-19-skill-rune-synergy-design.md)의 레벨 해금·탤런트·진화 규칙을 바꾸는 제안이라 **결정을 받은 뒤** 구현한다.

---

## 1. 장비창 — "등불 성물함"

**문제**: 지금 장비창은 기능은 갖췄지만, 모든 칸이 같은 네모 틀이라 어느 게임에서나 볼 수 있는 화면이다. 등불지기만의 얼굴이 없다.

**콘셉트**: 영웅이 등불 아래 받침돌 위에 서 있고, 장비는 그 둘레에 **부위마다 다른 모양의 성물 받침**에 놓인다. 세계관(등불이 기억을 태워 되살린다)과 같은 이야기를 화면이 한다.

| 요소 | 지금 | 새 디자인 | 에셋 |
|---|---|---|---|
| 가운데 | 64px 초상화 | **영웅 전신이 숨 쉬는 대기 애니메이션**(3배), 등불빛 웅덩이, 갈라진 받침돌 | 영웅 대기 애니(있음) + 받침돌·매단 등불(신규 2) |
| 장비 칸 | 같은 네모 9개 | 투구 = 뾰족 아치 벽감, 무기 = 길쭉한 방패꼴, 반지 = 룬 새긴 둥근 황동 고리 ×2, 목걸이 = 물방울 틀, 갑옷·장갑·장화·허리띠 = 둥근 쇠 메달 | 칸 틀 6종(신규) |
| 등급 표시 | 테두리 색 | 칸 아래 **보석** 색 + 아이콘 뒤 은은한 빛, 전설은 불티 | 보석 1종을 색으로 물들임(신규 1) |
| 연결 | 없음 | 칸에서 영웅으로 가는 가는 황동 선(별자리처럼) | 코드로 그림 |
| 능력치 | 어두운 상자 | 낡은 양피지 카드에 큰 금빛 숫자 | 양피지 9-slice(신규 1) |
| 가방 | 네모 격자 | 나무 궤짝 안쪽, 모서리가 둥근 칸, 등급 빛 | 궤짝 판·칸(신규 2) |
| 창 틀 | 일반 장식 틀 | 그을린 쇠 + 가장자리 불씨 빛, 모서리 해골·등불 장식 | 창 틀 9-slice(신규 1) |

- 정보 배치(인형 · 큰 숫자 · 가방 · 비교 툴팁 · 조작)는 이미 만든 것을 그대로 쓰고, **그림과 모양만** 바꾼다.
- 새 에셋은 약 14장이다(PixelLab `create_ui_asset`·`create_image_pro`, 하위 세션). 생성 수는 장당 10~25회, 합계 약 200회 이내로 잡는다.

## 2. 스킬 — "기억의 나무"

### 2.1 지금 구조와 문제
- 스킬은 레벨이 되면 저절로 열리고(직업마다 15개 + 궁극 2), 탤런트는 3갈래 × 40포인트에 자동 분배되며, 진화는 "사용·문양·정수 중 둘"이다.
- 결과적으로 성장이 **세 화면에 흩어져 있고**(고리·탤런트·도감), 무엇을 골라야 강해지는지 한눈에 안 보인다. 진화 조건의 정수는 직업이 엉켜 있다(시스템 보고서).

### 2.2 가안(추천) — 직업 하나에 나무 하나
등불(뿌리)에서 **세 갈래**가 위로 자라는 나무 하나에 스킬·탤런트·진화를 모은다. 고리(4칸 배치)는 그대로 두고, **나무에서 연 스킬만 고리에 넣을 수 있다.**

| 노드 | 모양 | 무엇 | 비용·조건 |
|---|---|---|---|
| 뿌리 | 등불 | 기본 공격 | 처음부터 |
| 스킬 | 큰 원(청동 고리 안에 아이콘) | 액티브 스킬 해금 | 1포인트 + 지금의 해금 레벨 |
| 변형 | 작은 마름모, 스킬마다 2개 | 그 스킬의 규칙 하나(예: 분신 +1, 범위 +25%, 재사용 −15%, 다른 원소로 변환) | 1포인트 |
| 패시브 | 작은 원 | 지금 탤런트의 수치(피해·생명·공명 등) | 1포인트 |
| 핵심 | 별 | 지금 탤런트 핵심 9개(갈래마다 3) | 3포인트, 그 갈래에 10/20/30포인트 이상 |
| 진화 | 스킬 노드 위의 장식 큰 원 | 그 스킬의 진화형 | 1포인트 + **그 스킬 숙련 20**(쓴 만큼 자람 유지). 문양·정수 조건은 없앤다 |
| 궁극 | 줄기 꼭대기 | 궁극기 2개 중 하나 | Lv30 |

- **갈래**는 지금 탤런트 갈래 이름을 쓴다. 예: 바람사냥꾼은 폭풍(전격)·생존·역병(부패·공허), 잿불기사는 잿불·불굴·잿더미.
- **포인트**는 통합 레벨마다 1점이다(최대 약 99점). 나무 전체는 약 130점이라 **다 찍을 수 없고**, 고르는 데서 빌드가 갈린다.
- **방치 편의**: "추천 경로 자동 분배"를 기본으로 켠다. 고른 추천 고리에 맞춰 순서대로 찍는다. 끄면 손으로 찍고, 초기화는 무료다.
- **보이는 성장**: 노드를 찍으면 가지가 그 원소색으로 불이 들어오고, 스킬 노드에는 숙련 레벨 고리가 차오른다. 숙련(쓴 만큼 레벨, 10레벨마다 분신)은 그대로 둔다.
- **화면**: 왼쪽 2/3에 나무, 오른쪽에 선택한 노드 카드(설명, 찍기 전 미리보기 "초당 피해 ▲+8%", 변형 2개), 아래에 고리 4칸 바(나무에서 끌어다 놓기).
- **사라지는 것**: 탤런트 창(나무로 합침), 진화의 "셋 중 둘" 조건, 레벨이 되면 스킬이 저절로 열리는 규칙.

### 2.3 나안 — 스킬마다 작은 전문화 트리 (Last Epoch 방식)
- 스킬 하나하나가 숙련 레벨로 자기 트리 포인트를 얻어, 그 스킬의 변형(분신·범위·원소·추가 효과)을 고른다. 탤런트는 따로 남는다.
- 장점: "쓸수록 자란다"는 우리 핵심과 딱 맞는다. 단점: 트리가 15개라 화면이 많고, 방치 중에는 대부분 자동으로 정해져 고를 맛이 약하다.

### 2.4 추천 이유
가안은 성장이 **한 화면 한 나무**에 모이고, 화면을 열었을 때 "어디로 자라는지"가 그림으로 보인다(D4 스킬 트리 개편의 방향). 나안의 장점(쓸수록 자람)은 가안에서도 숙련과 진화 조건으로 살린다.

### 2.5 영향 범위(가안)
- Sim: 노드 정의·포인트·조건·자동 분배(새 `SkillTree`), 스킬 해금과 진화 판정 교체, 탤런트를 패시브·핵심 노드로 옮김, 세이브(찍은 노드 목록), 기존 세이브는 지금 상태에 맞춰 자동 분배로 변환.
- View: 나무 화면(노드·가지·카드·고리 바), 고리 창은 나무 화면 아래 바로 합침.
- 새 에셋: 노드 틀 4종(스킬·변형·핵심·진화), 나무 줄기·가지 조각 또는 코드로 그리는 가지, 뿌리 등불.
- 테스트: 포인트 계산, 조건, 자동 분배, 세이브 변환, 60시간 시뮬(성장 속도가 지금과 크게 다르지 않게).
