## 트랙 2 · 다중 레이어 입체감 — **시험 후 버림 (11-22)**

결과: 먼 층(0.5배속, 막 소품을 어둡게)과 가까운 층(1.3배속, 사슬·거미줄 실루엣)을 만들어 같은 장면 전후·빌드 녹화로 비교. 쿼터뷰에서는 바닥이 화면 대부분을 덮고 빈 공간은 색 보정·비네트로 거의 검게 눌려, 먼 층은 3배 밝혀도 "떠다니는 잡동사니"로만 보였고 가까운 층은 드물게 보이며 시야만 가림. 깊이감은 빛(산란·파도·막별 빛 행동)이 더 잘 만든다 → 코드 제거(백업은 세션 스크래치패드).

(원래 계획)

도트 레이어를 깊이별로 2~3겹 깔아 카메라가 움직일 때 속도를 달리한다(패럴랙스).
- 아래층: 바닥 밖 심연(어두운 바닥·잔해를 0.5배속, 흐리게) → 맵이 공중에 뜬 디오라마처럼 보임
- 위층: 화면 가까이 매달린 사슬·뿌리·고드름 실루엣(1.3배속, 어둡게) → 앞에 뭔가 있는 깊이
- 평가: 같은 장면 캡처 전후 비교. 의미 없으면 버린다.

## 트랙 3 · 성장 줌

초반엔 영웅을 크게, 이동 속도·공격 범위가 커질수록 연속으로 줌 아웃해 최종 시야까지.
- 문제: 지금은 픽셀 퍼펙트(정수 배율)라 연속 줌이 안 된다. 그냥 소수 배율이면 픽셀이 떨린다.
- 기술: 월드를 정수 배율로 렌더한 뒤 "샤프 바이리니어"(픽셀 경계만 부드럽게) 업스케일로 소수 배율 표시. 업계에서 쓰는 방식이라 바로 진행.
- 줌 = f(이동 속도, 공격 범위, 레벨), 최저(가까이)·최종(멀리) 두 값 사이를 부드럽게.

## 트랙 4 · 환생 증강 카드 (새 시스템)

- 환생 직후 1장, Lv20에 2번째, Lv40에 3번째 칸. 칸마다 3장 중 1장 고르기, 칸마다 리롤 1회.
- 카드는 직업·갈래(스킬 트리 탭)에 편파적: 원소 피해 +%, 특정 스킬 치명 피해 +%, 특정 스킬 사용 시 확률로 다른 효과(예: 갈래 화살 → 독무), 일반(치명 확률 등).
- 목적: 갈래 하나를 타면 나머지를 버려야 하는 문제를 환생마다 다른 갈래로 유도.
- 갈래별 스킬 세트 저장·전환(카드에 맞춰 한 번에 바꾸기).
- 연출: 롤 증바람·뱀서 레벨업처럼 가챠 느낌 강하게(카드 회전·빛줄기·등급별 색·효과음).

### 4-1 카드 설계 초안

- 등급 3단: **은**(흔함) · **금** · **프리즘**(드묾). 등급이 높을수록 수치가 크고 연출이 화려하다(프리즘은 무지개 빛줄기·화면 섬광).
- 카드 종류 4가지
  1. 원소 강화: "냉기 피해 +50%" (원소 = 화염·냉기·번개·역병·공허)
  2. 스킬 특화: "갈래 화살 치명 피해 +50%", "축복의 망치 범위 +40%"
  3. 스킬 연계(발동): "갈래 화살 적중 시 20% 확률로 독구름", "화염구가 처치하면 작은 폭발"
  4. 일반: 치명 확률, 공격 속도, 생명력, 이동 속도
- 직업마다 갈래 3개 × 카드 6~8장 + 일반 6장. 한 번에 뽑는 3장은 서로 다른 갈래가 섞이게(갈래 쏠림 강제).
- 칸: 환생 직후 1칸, Lv20 2칸, Lv40 3칸. 칸이 열릴 때 3장 펼침 → 1장 선택. 칸마다 리롤 1회(3장 전부 다시).
- 방치 중(아무도 안 고를 때) 30초 지나면 자동 선택(현재 스킬 세트에 가장 맞는 카드).
- 결정론: 카드 뽑기는 전용 RNG(시드 + 환생 횟수), 세이브에 저장.

### 4-2 스킬 세트 저장

- 갈래(탭)별로 스킬 배치 4칸 + 변형 선택을 세트로 저장. 카드를 고르면 그 카드 갈래의 세트로 바로 바꿀지 묻는다(자동 진행이면 바로 전환).
