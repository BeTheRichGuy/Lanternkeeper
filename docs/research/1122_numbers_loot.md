## 0. 요약 (먼저 읽기)

1. 숫자 문제의 핵심은 "디자인된 위계 없이 전부 같은 크기로 쏟아지는 것"이다. 디아블로 4 후반이 정확히 이 사례이고, 플레이어들이 숫자를 끄는 쪽을 택했다. 해법은 (a) 위계 3~4단 (b) 같은 대상 연타 병합 (c) 화면 동시 표시 상한 + 우선순위 퇴출 (d) 옵션 4종이다.
2. 워프레임의 "Enhanced" 모드(큰 타격·치명타는 더 오래 남기고 나머지는 후순위)가 우리가 따라갈 가장 구체적인 선례다.
3. 전리품은 "등급별 연출 계단"이 핵심이다. 보통은 거의 무연출, 희귀는 짧은 빔+소리, 전설은 지속 빔+전용 사운드+미니맵 별+화면 순간 연출. 자동 줍기는 "바로 빨려 들어감" 대신 **등급이 높을수록 바닥에 머무는 시간(공개 지연)을 늘린 뒤 가방으로 날아가는 2단계**로 보상감을 만든다.
4. 킬 연속은 방치형에서는 상시 노출하면 소음이 된다. 임계 단계(10/25/50/100)에서만 짧은 배너, 상시는 작은 카운터+타이머 바만.

### 1.2 일반 원칙 (사실 + 추론)

- **[사실]** 숫자는 "튀어나오고(pop) → 위로 떠오르며 → 사라질 때" 만족스럽고, 그냥 나타났다 사라지면 밋밋하다는 것이 튜토리얼들의 공통 결론이다.
- **[사실]** D2는 숫자 자체가 없었고, D4 팬들이 "D1/D2처럼 끌 수 있게"를 요구한다. 우리 UI가 D2풍이므로 **기본값을 "절제"로 두는 것이 장르 정서와 맞다**. **[추론]**
- **[추론]** 방치형은 플레이어가 개별 타격을 조작하지 않으므로 숫자의 기능은 "정보"가 아니라 "리듬/규모 체감"이다. 그래서 개별 숫자를 전부 보여줄 이유가 약하고, 합산·요약 숫자가 더 적합하다.
- **[추론]** 후반 인플레(수천만~수억)는 폰트 폭을 폭발시키므로 축약(만/억)을 기본으로 한다. 한국어 사용자이므로 K/M보다 **만/억/조**가 직관적이다. 영문판 대비 설정으로 전환 가능하게 둔다.

### 1.4 병합·상한 규칙(핵심)

1. **대상별 병합 창 120ms**: 같은 대상·같은 속성의 일반 타격은 한 숫자로 합산(다단히트 스킬이 숫자 5개 대신 1개). 치명타는 병합하지 않고 따로 띄우되 T3 이상은 합산에서 분리.
2. **DoT은 대상당 500ms 합산** 틱(1.0s는 모드 기본값이나 방치형은 반응이 느려 보이므로 0.5s 권장).
3. **AoE 요약**: 한 번의 광역기로 대상 ≥ 6이면 개별 숫자 대신 **상위 3개 + 클러스터 중심에 "합계 N"**(24px, 황금)을 1개 표시. 제안: 합계 표시는 250ms 윈도.
4. **동시 표시 상한 24개**(전역), 대상당 3개. 초과 시 퇴출 순서: 가장 낮은 단계·가장 오래된 것부터. T3 이상과 보스 숫자는 퇴출 금지(슬롯 8개 예약).
5. **사망 시 flush**: 대상이 죽으면 대기 중인 합산을 즉시 확정 표시(마지막 타격 숫자가 사라지지 않게).
6. **오브젝트 풀**: 사전 생성 40개, 부족 시 가장 오래된 T1 재활용. 힙 할당/GC 없음(문자열 포맷은 캐시 테이블 또는 숫자→스프라이트 글리프 직접 배치).
7. **빈도 제한**: 한 프레임에 생성 가능한 숫자 4개(나머지는 다음 프레임 큐, 큐 길이 16 초과 시 폐기).

### 2.3 자동 줍기를 보상감 있게 만드는 법 [추론]

1. **두 박자 구조**: (1) 드롭 아크(0.4s, 바운스) + 공개 지연 (2) 흡수 비행. 지연 동안 빔/사운드/라벨이 읽히고, 그 뒤에 영웅이 아니라 **가방 아이콘**으로 날아가 "내 소유가 되었다"가 보인다.
2. **가속 곡선**: 흡수는 ease-in(처음 느리게 → 빠르게)이 끌림 느낌. 일반 0.25s, 전설 0.6s. 이동 중 꼬리(trail) 3~5개 잔상.
3. **도착 피드백**: 가방 아이콘 펄스(스케일 1.0→1.2→1.0, 150ms), 등급색 플래시, 짧은 "착" 소리. 일반은 합산 카운터만 숫자 상승.
4. **합산 로그**: 화면 우하단(또는 D2식 하단 메시지)에 등급색 한 줄 로그, 일반은 "+37 일반 아이템"처럼 묶음. 전설만 개별 항목 + 3초 유지.
5. **쓰레기 숨김**: PoE 필터 철학과 같이 낮은 등급은 라벨 자체를 숨기는 필터(자동 분해/숨김)를 제공해 중요한 것이 눈에 띄게.
6. **복귀 요약**: 방치 복귀 시 "획득 결과" 패널에서 전설/희귀를 큰 카드로 재생(슬롯머신식 순차 공개). 방치형은 실시간 드롭을 놓칠 수 있어 이 화면이 사실상 두 번째 드롭 연출이다.
7. **성능**: Vampire Survivors의 젬 응축처럼, 일반 드롭은 바닥에 쌓이지 않게 즉시 합산 처리(오브젝트 수 상한 40).
